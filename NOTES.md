First release of LockBox, an encrypted private folder for Android.

- Photos, videos, audio, documents, notes and cards, encrypted with AES-256-GCM on the phone
- Password or PIN with optional fingerprint, and a recovery code shown once at setup
- Built-in viewers, folders, tags, search and a 30-day recycle bin
- Locks itself; growing waits and a log after wrong tries
- Calculator disguise, encrypted backup file, no internet permission

**Read first:** uninstalling LockBox deletes everything in it. Make a backup file (Settings > Back up and restore) and keep it off the phone. See https://customgpter.github.io/lockbox/#first

Install steps and full notes: https://customgpter.github.io/lockbox/releases.html
