Version 1.0

First release

LatestReleased 18 November 2026

Added

  • A private folder for photos, videos, audio, documents and any other file, encrypted with AES-256-GCM, with a separate key for every file.
  • File names, folders, tags, notes, cards and preview pictures are encrypted as well.
  • Unlock with a password or a PIN of 4 to 12 digits, with optional fingerprint. Setup says which choice is strongest.
  • A 20-character recovery code, shown once at setup, and a way to make a new one.
  • The main key is locked with your PIN or password (Argon2id) and again with a key in the phone's security hardware.
  • Adding files from the phone's file picker or the Share menu. Each file is read back and checked before the original is removed.
  • Built-in viewers for photos, videos, audio, PDFs and text, decrypting as you look.
  • Encrypted notes, and cards for logins, bank cards, ID documents and Wi-Fi passwords, with hidden values and a clipboard that clears itself.
  • Folders inside folders, tags, favourites, search, sorting, grid and list views, and a 30-day recycle bin.
  • Locking when the phone screen turns off and after a chosen time without a touch, plus a quick-panel tile, a home-screen button, face-down and shake to lock.
  • Growing waits after five wrong tries, a break-in log, an optional front-camera photo and an optional delete-everything after a chosen number of wrong tries.
  • A calculator disguise with a real, working calculator, and three names to choose from.
  • An encrypted backup file with its own password, and restore at first setup.
  • Check all files, and a security check for a rooted phone or a tampered copy of the app.
  • A page of important notes at setup that has to be ticked, and Help and important notes in Settings.
  • Dark, light and follow-the-phone themes. Screenshots and the recent-apps preview are blocked.
  • No internet permission.

Installing and updating

  • When you download, Chrome may warn that the file might be harmful. It shows this warning for app files that do not come from Google Play. Choose Download anyway.
  • Open the downloaded file. The first time, Android asks you to allow your browser or file manager to install apps. Allow it, then tap Install.
  • Google Play Protect may say it does not recognise the app, or block it, because LockBox does not come from Google Play. Choose More details, then Install anyway.
  • Open LockBox, choose how to unlock, and write down the recovery code it shows you. It is shown once.
  • Read the page of notes that follows. It explains what deletes the vault and how to keep a spare copy. The same notes are on this site under Read this before you put anything in.
  • Make a backup file before you rely on LockBox for anything you could not replace: Settings › Back up and restore.
  • To update, download the latest version and install it over the one you have. Everything in the vault is kept. Never uninstall first: uninstalling deletes the vault.
  • Every version is signed with the same key, so Android accepts an update only if it comes from the same developer. LockBox also checks its own signature and warns you if the copy you have is not the genuine one.
